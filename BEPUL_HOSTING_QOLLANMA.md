Siz **hech qanday pul to'lamasdan** va kompyuteringizni yoqib o'tirmasdan botni 24/7 ishlatishingiz mumkin!

---

## ⚡️ 2 daqiqalik BEPUL joylashtirish ketma-ketligi:

### 1-qadam: GitHub ga joylash
1. [GitHub.com](https://github.com) saytidan bepul ro'yxatdan o'ting.
2. Yangi kod saqlagich (Repository) yarating (masalan: `anime-bot`).
3. Ushbu kompyuteringizdagi loyiha papkasidagi barcha fayllarni u yerga yuklang.

### 2-qadam: Render.com da bepul botni qo'shish
1. [Render.com](https://render.com) saytiga kiring va GitHub orqali bepul kiring (**Sign Up with GitHub**).
2. **"New +"** tugmasini bosib, **"Web Service"** ni tanlang.
3. GitHub dagi `anime-bot` loyihangizni tanlang ("Connect").
4. Sozlamalar:
   - **Name:** `anime-bot`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python main.py`
   - **Instance Type:** `Free` (MUTLAQO BEPUL)

5. Pastroqda **"Environment Variables"** bo'limiga kiring va o'z tokeningizni qo'shing:
   - `BOT_TOKEN` = `7744383424:AAG...SIZNING_TOKENINGIZ`
   - `ADMIN_PASSWORD` = `anime2026`

6. **"Create Web Service"** tugmasini bosing!
